# Текстура корабля

## Файл: `ship.png`

Здесь должна быть текстура корабля в формате PNG.

### Рекомендации:
- **Размер**: 64x64 или 128x128 пикселей
- **Формат**: PNG с прозрачным фоном
- **Ориентация**: корабль должен быть направлен вверх (нос в верхней части изображения)
- **Центр вращения**: должен быть в центре изображения

### Варианты создания:
1. **Нарисовать вручную** - в любом графическом редакторе
2. **Сгенерировать в AI** - например, в Midjourney, DALL-E или Stable Diffusion
3. **Скачать готовую** - с сайтов с бесплатными спрайтами

### Примеры запросов для AI:
- "spaceship sprite pixel art white and blue 64x64"
- "fighter jet top view sprite game art"
- "sci-fi spaceship icon minimal design"

### Если текстура не найдена:
Игра будет использовать заглушку `badlogic.jpg` (белый квадрат с логотипом libGDX).
