## 🎯 О проекте

**Astro** - это современный 2D космический шутер, созданный на **LibGDX** с использованием **Java 21**. Игра сочетает в себе классический геймплей Asteroids с инновационными механиками:

- 🎯 **Автоматические ракеты** с самонаведением
- 👾 **Орк-астероиды** - враги, которые стреляют в ответ
- 🌌 **Динамическая камера** с зумом и прокруткой
- ⚡ **Оптимизированная производительность** с настраиваемым FPS
- 🎨 **Современная графика** с частицами и эффектами

## ⚡ Возможности

### 🚀 Игровые механики
- **Классический геймплей** - уничтожайте астероиды и выживайте
- **Автоматические ракеты** - каждую секунду запускается самонаводящаяся ракета
- **Орк-астероиды** - враги, которые стреляют короткими очередями
- **Система уровней** - с каждым уровнем врагов становится больше

### 🎮 Технические особенности
- **Динамическая камера** - следует за игроком с плавной прокруткой
- **Масштабирование** - зум камеры для детального обзора
- **Оптимизированные коллизии** - быстрые и точные проверки столкновений
- **Настраиваемый FPS** - от 30 до неограниченного количества кадров

### 🎨 Визуальные эффекты
- **Звездное небо** - динамический фон с 800 звездами
- **Система частиц** - взрывы и визуальные эффекты
- **Плавная анимация** - все объекты движутся естественно
- **Антиалиасинг** - сглаженная графика

## 🎮 Управление

### Основное управление
| Клавиша | Действие |
|---------|----------|
| `WASD` / `↑↓←→` | Движение корабля |
| `SPACE` | Стрельба |
| `ENTER` | Сброс зума камеры |

### Камера
| Клавиша | Действие |
|---------|----------|
| `+` / `=` | Приближение |
| `-` | Отдаление |
| `ENTER` | Сброс зума |

### Настройки FPS
| Клавиша | Действие |
|---------|----------|
| `F` | Включить/выключить FPS счетчик |
| `` ` `` | Увеличить лимит FPS |
| `1` | Уменьшить лимит FPS |

### Доступные лимиты FPS
- **30 FPS** - для слабых систем
- **60 FPS** - стандартный (по умолчанию)
- **120 FPS** - для высокочастотных мониторов
- **240 FPS** - для киберспортивных мониторов
- **UNLIMITED** - без ограничений

## 🔧 Установка

### Требования
- **Java 21** или выше
- **Gradle 8.5** (включен в проект)
- **Git**

### Быстрый старт

```bash
# Клонируем репозиторий
git clone https://github.com/your-username/astro.git
cd astro

# Запускаем игру
./gradlew :desktop:run
```

### Сборка для разных платформ

```bash
# Desktop (Windows, macOS, Linux)
./gradlew :desktop:run

# Android
./gradlew :android:assembleDebug

# HTML5 (браузер)
./gradlew :html:superDev
```

### Разработка

```bash
# Сборка проекта
./gradlew build

# Запуск тестов
./gradlew test

# Очистка
./gradlew clean
```

## 🏗️ Архитектура

```
Astro/
├── core/                 # Основная игровая логика
│   ├── entities/        # Игровые объекты
│   ├── gamestates/      # Состояния игры
│   ├── managers/        # Менеджеры (ввод, камера)
│   └── game/           # Главный класс игры
├── desktop/            # Desktop версия
├── android/            # Android версия
├── html/               # HTML5 версия
└── ios/                # iOS версия
```

### Ключевые компоненты

- **`PlayState`** - основное игровое состояние
- **`Camera`** - система камеры с зумом и прокруткой
- **`AutoRocket`** - автоматические самонаводящиеся ракеты
- **`OrkAsteroid`** - враги, которые стреляют
- **`Enemy`** - базовый класс для всех врагов

## 🚀 Производительность

Игра оптимизирована для максимальной производительности:

- **Оптимизированные коллизии** - использование квадратов расстояний вместо `Math.sqrt()`
- **Кэширование** - поиск ближайших врагов кэшируется
- **ShapeRenderer оптимизация** - минимизация OpenGL вызовов
- **Настраиваемый FPS** - контроль производительности в реальном времени

### Профилирование
Включите FPS счетчик (клавиша `F`) для просмотра:
- Текущего FPS
- Количества объектов
- Времени выполнения каждого компонента
