# Astro - Космическая Игра

Космическая игра на базе LibGDX с системой фиксированного временного шага.

## 🚀 Особенности

### Игровые механики
- **Космический корабль** с управлением и частицами двигателя
- **Самонаводящиеся ракеты** с серыми частицами следа
- **Астероиды** с реалистичной физикой
- **Система коллизий** и уничтожения объектов
- **Камера** с плавным следованием за игроком

### Технические достижения
- **✅ Фиксированный временной шаг** - игровая логика независима от FPS
- **✅ Система частиц** - красивые эффекты для корабля и ракет
- **✅ Оптимизированная производительность** - стабильная работа на всех устройствах
- **✅ Модульная архитектура** - легко расширяемый код
- **✅ Кроссплатформенность** - поддержка Desktop, Android, iOS, Web

## 🎮 Управление

### Desktop
- **WASD** - движение корабля
- **Пробел** - стрельба
- **R** - самонаводящиеся ракеты
- **ESC** - выход

### Mobile
- **Виртуальный джойстик** - движение
- **Кнопки стрельбы** - различные типы оружия
- **Жесты масштабирования** - зум камеры

## 🛠 Техническая архитектура

### Система фиксированного временного шага
```
Игровой цикл:
├── Получение deltaTime
├── Накопление времени в аккумуляторе
├── Обновление игровой логики (60 FPS)
└── Отрисовка (переменный FPS)
```

### Основные компоненты
- **TimeManager** - управление временем и фиксированным шагом
- **InterpolationManager** - плавная интерполяция для отрисовки
- **GameConfig** - централизованная конфигурация
- **GameStateManager** - управление состояниями игры
- **Camera** - система камеры с зумом
- **Particle System** - система частиц

### Структура проекта
```
core/src/com/gdx/
├── entities/          # Игровые объекты
│   ├── Player.java    # Космический корабль
│   ├── AutoRocket.java # Самонаводящиеся ракеты
│   ├── Asteroid.java  # Астероиды
│   └── Particle.java  # Система частиц
├── managers/          # Менеджеры
│   ├── GameStateManager.java
│   ├── Camera.java
│   └── AndroidInputManager.java
├── utils/             # Утилиты
│   ├── TimeManager.java
│   ├── InterpolationManager.java
│   └── GameConfig.java
└── gamestates/        # Состояния игры
    ├── PlayState.java
    ├── MenuState.java
    └── SettingsState.java
```

### Оптимизации
- **Фиксированный временной шаг** - стабильная производительность
- **Ограничение deltaTime** - защита от скачков времени
- **Аккумулятор времени** - предотвращение спирали смерти
- **Интерполяция** - плавная отрисовка при низком FPS

## 🎯 Настройки

### Доступные настройки в UI:
1. **Logic FPS** (30-240) - частота обновления игровой логики
2. **Render FPS** (30-240, UNLIMITED) - максимальный FPS рендеринга
3. **Particles** (100-5000) - максимальное количество частиц
4. **Player Speed** (100-1000) - скорость игрока
5. **Bullet Speed** (100-1000) - скорость пуль

### Управление настройками:
- **↑↓** - переключение между настройками
- **←→** - изменение значений
- **ENTER** - подтверждение
- **ESC** - возврат в меню
- **Подсказки** - описания и рекомендации для каждого параметра

### Рекомендуемые конфигурации:
```
Стандартная: Logic FPS: 60, Render FPS: 60, Particles: 1000
Мощные устройства: Logic FPS: 120, Render FPS: 120, Particles: 2000
Слабые устройства: Logic FPS: 30, Render FPS: 30, Particles: 500
```

## 📈 Преимущества системы фиксированного временного шага

### 1. Независимость от FPS
- Игровая логика работает одинаково на всех устройствах
- Скорость движения, таймеры, физика - все стабильно
- Нет зависимости от производительности устройства

### 2. Предсказуемость
- Все игровые механики работают с постоянной скоростью
- Коллизии, стрельба, движение - все синхронизировано
- Отсутствуют "спирали смерти" при низком FPS

### 3. Масштабируемость
- Игра работает одинаково на слабых и мощных устройствах
- Можно ограничивать FPS без влияния на геймплей
- Поддержка различных частот обновления экрана

## 🔧 Разработка

### Добавление новых объектов
```java
public class NewGameObject {
    public void update(float dt) {
        // dt теперь всегда равен FIXED_TIMESTEP (1/60 секунды)
        x += dx * dt;  // Движение с постоянной скоростью
        timer += dt;   // Таймеры работают стабильно
    }
}
```

### Использование интерполяции
```java
// В методе draw()
float[] interpolatedPos = InterpolationManager.interpolatePosition(
    previousX, previousY, currentX, currentY
);
```
